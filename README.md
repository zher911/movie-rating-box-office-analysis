## Project Overview
This project explores the relationship between movie ratings and box office revenue.  
The target users are film investors, producers, and entertainment media creators.  
The purpose of the project is to examine whether higher-rated movies tend to perform better commercially.  
This analysis helps users better understand movie market patterns and supports more informed decisions.

---

## Data Source
The dataset used in this project is `enhanced_box_office_data(2000 - 2024)u.csv`.  
It contains movie-related information such as title, genre, year, rating, and revenue.  
This dataset was selected because it is directly relevant to the research question.

**Source:** [https://www.kaggle.com/datasets/aditya126/movies-box-office-dataset-2000-2024]  
**Access date:** [2026.4.22]

---

 ## Analytical Question
The main question of this project is:

**Is there a relationship between movie ratings and box office revenue?**

---

## Target Users
This project is designed for:
- Film investors
- Film producers
- Entertainment media creators

These users may benefit from understanding whether rating is associated with commercial performance.

---

## Methods
The analysis was conducted in Python using a Jupyter Notebook.  
The main steps included:

1. Loading the dataset  
2. Inspecting the dataset structure, column names, and missing values  
3. Cleaning the data by removing duplicates and invalid values  
4. Converting key variables such as rating, revenue, and year into numeric format  
5. Creating visualisations to examine:
   - distribution of movie ratings
   - distribution of box office revenue
   - relationship between rating and revenue
6. Conducting a simple correlation analysis  
7. Interpreting findings and discussing limitations

---

## Key Findings
- Higher-rated movies appear to earn more on average, but the relationship is not perfectly linear.  
- Box office revenue is uneven,some movies with moderate ratings still achieve very high box office revenues.  
- Rating may be related to commercial performance, but it is clearly not the only factor influencing box office success.

## Limitations
- The dataset does not include variables such as marketing budget, franchise popularity, or release timing.  
- Ratings alone cannot fully explain box office success.  
- Correlation does not imply causation.  

---

## Conclusion
This project provides a simple data-based analysis of the relationship between movie ratings and box office revenue.  
For film investors, producers, and entertainment media creators, the results suggest that rating may matter, but it is only one factor in a more complex commercial outcome.
